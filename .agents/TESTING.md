# Testing

The executable smoke test checks placeholders, replacement, quantity validation, page fitting, and multi-page planning and passes with .NET 10. The solution also builds successfully against the locally installed CorelDRAW interop assemblies. On 2026-09-16, a real v27.1.0.129 temporary-document test created a grouped rectangle plus artistic text placeholders, captured the selected group, generated two Nursery and one KG-I copies, and reported the original plus generated shapes on one page. `Build-Release.ps1` and the extracted package install/uninstall workflow still require rerunning after the managed dependency additions. Interactive WPF UI generation, formatting preservation, undo/redo, large quantities, and automatic startup remain unverified.
