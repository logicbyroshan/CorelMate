# Support

CorelMate currently targets CorelDRAW Graphics Suite 2026, internal v27.1.0.129, on Windows x64.

Before opening an issue:

1. Confirm the installed CorelDRAW version.
2. Run the Release build and smoke test.
3. Check [.agents/TROUBLESHOOTING.md](.agents/TROUBLESHOOTING.md).
4. Check [.agents/KNOWN_LIMITATIONS.md](.agents/KNOWN_LIMITATIONS.md).
5. Search existing GitHub issues.

Include the operating system, CorelDRAW version, CorelMate commit/release, exact workflow, expected result, actual result, and relevant logs. Never attach credentials, API keys, or private artwork.
