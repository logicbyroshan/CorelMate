# Project

CorelMate is an open-source productivity addon that runs inside CorelDRAW. It currently includes a generic placeholder-driven repeated artwork generator and recursive Convert Text to Curves workflow, plus an AI provider abstraction for future work. Version 0.1.0 is pre-release: the core workflows are implemented and real-host tested in focused scenarios, while full interactive UI coverage and automatic `.addon` startup remain unverified.
